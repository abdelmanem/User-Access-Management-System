How to Use
Format

Enter one accessory per line with these columns separated by tabs or spaces:

Name | Asset Tag | Type | Manufacturer | Model | Serial | Status | Location
Required Fields
  • Name: Accessory name (e.g., "Dell Monitor 27")
  • Asset Tag: Unique identifier (e.g., "MON-001")
Optional Fields
  • Type: Monitor, Keyboard, Mouse, Dock, etc. (default: Monitor)
  • Manufacturer: Brand name
  • Model: Model number
  • Serial: Serial number
  • Status: In Service, In Storage, etc. (default: In Service)
  • Location: Physical location
Example
Dell Monitor MON-001 Monitor Dell 27"
Logitech Keyboard KEY-001 Keyboard Logitech K840
Mouse MOU-001 Mouse Logitech M705
Note: Asset tags must be unique. Duplicates will be rejected.
