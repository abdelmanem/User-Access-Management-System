Configuration Help
Common Configuration Examples:
  • Active Directory:
    • Server: ldap://dc.example.com:389 or ldaps://dc.example.com:636
    • Bind Username: CN=ServiceAccount,CN=Users,DC=example,DC=com
    • Base DN: DC=example,DC=com
    • Filter: (&(objectClass=user)(objectCategory=person))
    • Username Field: samaccountname (lowercase)
  • OpenLDAP:
    • Server: ldap://ldap.example.com:389
    • Bind Username: cn=admin,dc=example,dc=com
    • Base DN: ou=users,dc=example,dc=com
    • Filter: (objectClass=inetOrgPerson)
    • Username Field: uid
Important Notes:
  • Always test your connection before enabling LDAP authentication
  • Use lowercase field names for Active Directory (e.g., samaccountname, not sAMAccountName)
  • The bind user must have read access to the directory
  • Enable "Cache Passwords" to allow local login when LDAP server is unavailable
  • For SSL, use ldaps:// or enable "Use TLS" for STARTTLS
