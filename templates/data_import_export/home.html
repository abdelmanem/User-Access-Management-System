Export Instructions

Click on any export link to download the data as a CSV file. The files will contain all records from the database.

Import Instructions

When importing data, ensure your CSV files include the required columns and use UTF-8 encoding:

  • Users (required): username, email, first_name, last_name, employee_id, phone_primary, position. Optional columns: employment_type, employment_status, department_code, is_active, join_date (YYYY-MM-DD), password.
  • Departments (required): name, code, department_type. Optional columns: description, is_active, parent_department_code, head_of_department_employee_id.
  • Systems (required): name, code, system_type, criticality_level, environment_type. Optional columns: description, requires_approval, is_active, is_monitored, system_owner_employee_id, technical_lead_employee_id.

Important: Importing will create new records. Existing records will not be updated.
