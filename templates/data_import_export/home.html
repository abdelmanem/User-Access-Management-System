Import Instructions

When importing data, ensure your CSV files include the required columns and use UTF-8 encoding:

  • Users (required): username, email, first_name, last_name, employee_id, phone_primary, position. Optional columns: employment_type, employment_status, department_code, is_active, join_date (YYYY-MM-DD), password.
  • Departments (required): name, code, department_type. Optional columns: description, is_active, parent_department_code, head_of_department_employee_id.
  • Systems (required): name, code, system_type, criticality_level, environment_type. Optional columns: description, requires_approval, is_active, is_monitored, system_owner_employee_id, technical_lead_employee_id.
  • Hardware (required): name, asset_tag, hardware_type, status. Optional columns: manufacturer, model_number, operating_system, cpu, memory_gb, storage_capacity_gb, location, department_code, primary_user_employee_id, assigned_user_employee_ids (semicolon separated), related_system_codes (semicolon separated), purchase_date, warranty_expiration, end_of_life_date, is_virtual, requires_patch_management, last_inventory_check, next_inventory_check, ip_address, mac_address.

Important: Importing will create new records. Existing records will not be updated.

Active Directory Export Helper

Need a starting CSV straight from Active Directory? Download the ready-made PowerShell script below. It gathers usernames, contact details, department, status, description, and location fields. Run it on a domain-joined machine (with the RSAT ActiveDirectory module) and it will generate C:\ADUsers.csv ready for import.

  1. Open PowerShell as an administrator on a machine with AD RSAT tools.
  2. Run the script: .\export-ad-users.ps1 (adjust the download location as needed).
  3. Upload the generated ADUsers.csv using the Import Users form above.
